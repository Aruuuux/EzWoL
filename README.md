# EzWoL 
EzWoL is a professional **Bash wrapper** for the `wakeonlan` utility. It is designed to streamline remote hardware management through a secure, persistent, and aesthetic terminal interface. 

---

## 🌟 Key Features
* **Smart Wrapper**: Enhances the standard `wakeonlan` tool with persistent storage and automated broadcast calculation.
* **Global CLI Access**: Installed as a system-wide alias, allowing you to run `ezwol` from any directory.
* **Dynamic Terminal UI**: Features an auto-centering interface that scales with your terminal window size.
* **Full CLI Support**: Integrated flags for help (`-h`), version (`-v`), and automated uninstallation (`--uninstall`).
